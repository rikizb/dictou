# Stratégie Réseaux Sociaux — Cibler les Enseignants
## Playbook exécutable par un agent IA via Claude + Chrome

---

## Contexte & Objectif

**Cible principale :** Enseignants primaire (CP-CM2) français
**Où ils sont :** TikTok (ProfTok), Facebook groupes, Instagram, LinkedIn, YouTube
**Objectif :** 1 instit qui adopte Dictou = 25-30 familles inscrites automatiquement
**Ton :** Authentique, pédagogique, pas commercial

---

## PLATEFORME 1 — TikTok (ProfTok)

### Pourquoi
Les enseignants primaire sont massivement sur TikTok (#ProftTok, #InstitTok, #EnseignantTikTok). Ces comptes font 20K-200K abonnés. Un partage organique par 1 instit peut générer 500-2000 inscriptions en 24h.

### Comptes cibles à identifier (agent Chrome)
Rechercher sur TikTok :
- `#proftok` — trier par popularité récente
- `#institTikTok`
- `#enseignantprimaire`
- `#maîtresse`
- `#CP #CE1 #CE2` combinés à `#dictée`

**Critères de sélection :**
- 5K-500K abonnés
- Posts récents (< 30 jours)
- Engagement > 3% (likes/vues)
- Contenu FR, école primaire

**Liste cibles à construire :** 20-30 comptes

### Script de commentaire (à poster sur leurs vidéos récentes)
```
Super idée ! J'ai créé Dictou pour exactement ça — l'IA génère 
des phrases avec les mots de dictée de ta classe. 100% gratuit 
et les parents peuvent pratiquer à la maison avec le même lien.
Tu veux un accès test ? 🍎
```

**Règle :** max 5 commentaires/jour/compte pour éviter le shadowban. Varier légèrement le texte.

### Contenu à créer pour le compte Dictou TikTok
Format : 30-60 secondes, voix off + screen recording

**Vidéo #1 — La révélation**
```
Script :
"Vous êtes instit et vous passez 20 min par semaine à corriger 
les dictées... J'ai fait ça pour mes élèves. 
[montrer l'interface] 
J'entre les mots de la semaine, l'IA génère des phrases adaptées 
au niveau CP/CE1/CE2. Les parents reçoivent le lien et pratiquent 
à la maison. Et c'est gratuit. Dictou point com."
```

**Vidéo #2 — Le before/after**
```
Script :
"Avant : dictée papier du vendredi, 28 copies à corriger 😭
Après : les parents s'entraînent avec Dictou toute la semaine,
les mots arrivent maîtrisés le vendredi 🎉
[montrer la liste partagée + l'interface enfant]
Le lien classe en bio."
```

**Vidéo #3 — Démo rapide (60s)**
```
Script :
"Je vous montre en 60 secondes comment créer une liste 
de dictée pour votre classe sur Dictou.
1. Je tape mes mots de la semaine [demo]
2. Je clique 'Partager' [demo]
3. J'envoie le lien sur le groupe WhatsApp parents [demo]
Les enfants peuvent s'entraîner sans inscription.
Gratuit, en français, adapté CP au CM2."
```

## PLATEFORME 2 — Facebook Groupes Enseignants

### Groupes cibles (recherche agent Chrome)
Chercher sur Facebook :
- "Instits 2.0" (~150K membres)
- "Maîtresse t'as pas un truc pour..." 
- "Enseigner autrement - école primaire"
- "Les Cartables de nos Maîtresses"
- "CP CE1 CE2 CM1 CM2 - partage de ressources"
- "Enseigner au CP" / "Enseigner au CE1" etc.

**Filtrer :** groupes avec activité < 24h, > 10K membres, modérés (pas de spam)

### Post authentique à publier (1 fois par groupe, espacé de 3 jours)
```
Bonjour à tous ! 🍎

Je voulais partager un outil que j'ai trouvé pour les dictées 
— Dictou.com.

Le principe : je rentre les mots de dictée de ma classe, 
l'IA génère des phrases personnalisées adaptées au niveau. 
Je partage le lien avec les parents sur WhatsApp, 
et les enfants peuvent s'entraîner à la maison avec exactement 
les mots qu'on travaille en classe.

Ce que j'apprécie :
✅ Gratuit et sans pub
✅ Pas besoin de compte pour les élèves/parents
✅ Les mots sont dynamiques (si je change la liste, ça se met à jour)
✅ Niveaux CP → CM2

Est-ce que certains d'entre vous utilisent des outils similaires ? 
J'aimerais avoir vos retours !
```

**Règle importante :** Ne jamais mentionner "j'ai créé". Toujours parler en utilisateur. Si des gens posent des questions techniques, répondre normalement.

### Réponses aux commentaires (agent)
Si quelqu'un demande "c'est payant ?" :
```
Non, 100% gratuit ! Il y a juste un compte optionnel si on 
veut sauvegarder l'historique de progression, mais pour 
utiliser avec sa classe c'est immédiat sans inscription.
```

Si quelqu'un demande "comment je partage avec ma classe ?" :
```
Tu crées une liste, tu cliques sur Partager, et tu copies 
le lien. Tu peux l'envoyer sur ton groupe WhatsApp parents 
ou afficher le QR code en classe. Les parents cliquent 
et c'est parti, sans compte.
```

|---|---|---|---|
| TikTok | Commentaires | 20 | Réponses reçues |

| Instagram | Commentaires | 15 | Réponses + follows |
| LinkedIn | Posts + DMs | 3 | Vues + connexions |

### Rythme recommandé
- **Lundi** : 3 commentaires TikTok + 1 post Facebook
- **Mercredi** : 3 commentaires TikTok + 1 post Instagram
- **Vendredi** : 1 post LinkedIn + 3 commentaires YouTube
- **Dimanche** : analyser les métriques, préparer semaine suivante

## INSTRUCTIONS POUR L'AGENT CHROME

### Session type (30 min)
1. Ouvrir TikTok → chercher #proftok → trier récent
2. Identifier 3-5 vidéos récentes avec > 1K vues
3. Poster commentaire varié sur chaque
4. Ouvrir Facebook → aller dans groupe cible
5. Vérifier si déjà posté (chercher "Dictou" dans le groupe)
6. Si non → publier le post authentique
7. Répondre aux commentaires existants sur les posts précédents
8. Log les actions dans un fichier texte
